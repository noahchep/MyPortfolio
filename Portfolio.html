LAB #01

Site-to-Site ISAKMP IPsec VPN Configuration

Env: Cisco Packet Tracer

Problem Statement

Establish a secure, encrypted communications tunnel between two remote enterprise branches across an untrusted simulated Internet WAN link, ensuring confidentiality and data integrity without compromising throughput.

Approach & Tools Used

Tools: Cisco Packet Tracer, ISAKMP Security Association, AES-256 Encryption, SHA Hash algorithms, Pre-Shared Keys (PSK).

  • › Phase 1: Configured ISAKMP Crypto Policy (IKE Policy 10, DH Group 2, AES encryption).
  • › Phase 2: Created IPsec Transform-Set (esp-3des esp-sha-hmac) and ACL 101.
  • › Bound Crypto Map to outgoing WAN interfaces and verified tunnel via ping traffic.

Key Lessons Learned

Identified that Phase 1 ISAKMP parameters (Diffie-Hellman group and authentication key) must strictly match on both router endpoints; otherwise, renegotiation fails silently, dropping encrypted traffic flows.

LAB #02

Subnet Reconnaissance & Traffic Packet Analysis

Env: Kali Linux / Wireshark

Problem Statement

Perform passive and active network audits on a sandbox lab subnet to identify active hosts, open service ports, OS fingerprints, and cleartext credentials traversing unencrypted channels.

Approach & Tools Used

Tools: Nmap Security Scanner, Wireshark Packet Analyzer, Kali Linux Terminal.

# Active Reconnaissance Scan

nmap -sS -sV -O -p 1-1024 192.168.1.0/24

# Captured Packet Filter in Wireshark

http.request.method == "POST" || tcp.port == 21

Key Lessons Learned

Demonstrated how legacy protocols such as HTTP and FTP transmit sensitive payloads in plain text. Recommended enforcing TLS/HTTPS encryption and closing unused low-numbered service ports across internal hosts.
